## Kurzüberblick

Dieses Repository enthält das Bludit-Plugin **GitHub Backup**. Das Plugin sichert ausgewählte Bludit-Verzeichnisse über die GitHub REST API und unterstützt manuelle Backups, einen Scheduler ohne lokalen Cron sowie optional GitHub Actions.
