## Kurzüberblick / Short overview

### 🇩🇪 Deutsch

Dieses Repository enthält das Bludit-Plugin **GitHub Backup**. Das Plugin sichert ausgewählte Bludit-Verzeichnisse über die GitHub REST API und unterstützt manuelle Backups, einen Scheduler ohne lokalen Cron sowie optional GitHub Actions.

### 🇬🇧 English

This repository contains the **GitHub Backup** plugin for Bludit. The plugin backs up selected Bludit directories through the GitHub REST API and supports manual backups, a scheduler without local cron, and optional GitHub Actions.
